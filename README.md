# Winiger Frères — site internet

- **`site/`** : code source (Astro). Voir [`site/README.md`](site/README.md) pour la direction artistique, les sources vérifiées et la liste « À compléter ».
- **Racine du dépôt** : version publiée, générée par `cd site && npm install && npm run publish:pages`. C'est elle que sert GitHub Pages (branche `main`, dossier `/ (root)`).

Ne pas modifier les fichiers de la racine à la main : modifier `site/` puis relancer `npm run publish:pages`.
